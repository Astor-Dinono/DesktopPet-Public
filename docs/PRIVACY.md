# 隐私说明

陪伴、动画和计数在本地运行，没有账号、AI API 或第三方分析。仅主动点击“检查更新”时，更新器通过 HTTPS 访问官网的更新文件。

## 手动检查更新

“更多 → 检查更新”只在用户主动点击后初始化 Sparkle 更新器，通过 HTTPS 请求官网的签名版本清单；有新版时由用户确认下载和安装。默认不进行后台检查、自动下载或自动安装，不开启系统画像或分析。陪伴、动画和计数不依赖网络，断网仍可使用。

更新器不接入输入监听或计数存储，不附带输入内容、计数、位置或活动记录。更新的网络连接仍会向托管方暴露普通网络信息（例如 IP 地址）；HTTP 用户代理固定为 DesktopPet-Updater。更新器会在本机保存必要的版本检查偏好与更新缓存，不是输入历史。

版本清单和更新包必须通过 Ed25519 签名核验，验证失败不安装。签名私钥保存在开发者的钥匙串，不在程序、网站或下载包里。安装前补写计数与位置，更新只替换应用程序包，保留同一应用标识下的本地偏好；版本迁移仍需要实机验证。

## 可选计数

点击次数默认关闭。主动启用后，macOS 会请求“输入监控”授权，菜单可随时暂停。应用使用只读事件监听，不拦截或修改输入；只关注按下事件类型和键盘长按重复标志，不提取字符、键码、组合、事件时间戳、鼠标位置、硬件来源或目标应用，不保存事件对象或日志。

键盘、鼠标和触控板合并计数：普通非重复按键，以及左、右和其他鼠标按钮按下计一次。双击计两次；长按重复、单独修饰键变化、抬起、移动、滚动及拖动过程不计，拖动最初按下仍计一次。系统安全输入、锁屏、权限撤回和程序未运行期间可能漏计，不尝试补猜。

启用并授权后，键盘驱动尾巴，鼠标点击安静唤醒小狗并重置打盹时间。点击其他应用不会生成摸摸爱心、腮红或 duang。隐藏小狗后仍计数；暂停和系统睡眠时卸载计数监听。

## 本地保存

使用 UserDefaults 保存当前日期、今日次数、累计次数、计数启用偏好，以及位置、大小、朝向、位置锁定、数字框显示方式、自动打盹时长和互动特效搭配。当前汇总键为 `input.aggregate.v1`，兼容一次性迁移既有键鼠汇总。没有每日历史、逐次记录、输入内容、按键顺序或应用使用记录。

汇总约两秒分批写入，暂停、正常退出和休眠时补写；异常退出可能丢失最近尚未写入的一小段总数。今日随本地日期变化归零，累计保留。

## 指针与动画

透明区域穿透仅临时使用当前光标位置判断小狗和可见数字框是否接收点击，不保存坐标或轨迹，不与计数关联，不需要新增权限。隐藏或休眠时停止相关移动通知和动画。

仅小狗窗口内的真实点击或抚摸位置用于生成一枚互动特效。最多六颗位置在内存中保留约两秒，随后清除；休息或收起也会清除；拖动时让它自然飘完。独立特效窗口始终点击穿透，不读取其他应用的点击位置。

锁定位置后的按住抚摸只处理小狗自身收到的鼠标交互，不新增全局输入监听或权限。为判断有效移动与限制反馈频率，内存里临时保留本次起点、上个点、累计距离和反馈间隔，不记录轨迹或逐次事件；松开或取消后清空手势。只持久保存 `dog.positionLocked` 开关。抚摸回调不增加计数；如果已启用原有计数，最初的物理按下仍计一次，移动和松开不另计。

操作提示仅保存本机「不再提示」开关 `dog.interactionHintDisabled`，普通关闭只在本次运行生效。定位使用自身角色、数字框及屏幕几何，不读取其他应用或新增输入监听；查看和关闭提示不额外累加次数。

应用读取屏幕尺寸和系统“减少动态效果”偏好用于布局与动画，不请求屏幕录制或辅助功能权限。离屏预览只包含程序绘制的小狗。

选中桌面小狗或预览小狗后按 R 旋转只处理该选中窗口收到的快捷键事件，不监听其他应用的 R、不申请新权限，不保存按键或拖动轨迹。桌面小狗主动选中后才接收快捷键，Esc 或点击其他窗口取消选择。预览位置、朝向和选中状态只在内存中，不改变桌面小狗的位置设置。

互动特效可分别启用爱心、小花、小爪子和小星星，默认仅爱心，也可全部关闭。多选时每次摸摸随机出现一种并避免连续重复；仅保存四项开关，不保存出现顺序或随机选择历史。全局计数事件不产生这些特效。

悬停摸摸复用现有鼠标交互和透明区域检测，只在小狗头部或尾巴有效范围内判断停留及移动；仅临时保留停留时间、当前点和累计距离，离开、按下或取消即清除，不保存轨迹，不增加监听、权限或点击次数。
