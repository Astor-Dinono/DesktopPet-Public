## 下载与使用

1. 适用于 Apple 芯片 Mac，macOS 14 或以上：[下载 Mac build 46](https://desktop-pet-dog.pages.dev/updates/DesktopPet-0.1.0-b46-arm64.zip)
2. 下载解压后，将 DesktopPet.app 放进“应用程序”文件夹；当前为开发签名测试版，尚未完成 Developer ID 签名与公证，首次打开可能遇到系统安全提示，详见安装说明
3. 已安装的小狗可右键 → 更多 → 检查更新，确认后下载安装；原计数和设置继续保留
4. Windows 测试版可从官网下载；本仓库当前提供 Mac 版源码

## 小狗能做什么

1. 呼吸、眨眼、柔性摇尾巴、打盹与平滑醒来
2. 摸摸时脸红、弹性回弹，并随机飘出自选的爱心、小花、小爪子或小星星
3. 四档体型、两种尾巴大小、四向平滑旋转，以及顶部自动吸附；选中桌面小狗后按 R 转身
4. 可选的键盘、鼠标与触控板统一计数，数字默认悬停显示，也可设为常驻
5. 透明空白处点击穿透，隐藏或系统睡眠时停止动画，并响应系统“减少动态效果”设置

## 隐私

## 构建与测试

需要 macOS 14+、Swift 6 和 Xcode 工具链，Sparkle 依赖版本已锁定

```sh
swift build -c release
bash scripts/test.sh
```

本版纯小狗源码通过 109 项测试。打包和自己的本地开发签名方式见[构建说明](docs/BUILDING.md)，官方发布签名的私钥不包含在源码中
