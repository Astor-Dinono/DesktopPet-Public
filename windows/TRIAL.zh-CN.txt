小狗桌宠 · Windows 试用版 0.1.0 / build 10

这是给朋友试用的测试版，目标是 Windows 10（1809 或更新）/11 64 位（x64）。
已经在 Mac 上完成交叉构建；本次摸摸、双击拖动和提示气泡尚未在真正的 Windows 电脑上运行验收。
不要把这份说明当作兼容性或耗电保证。

开始使用
1. 从官网下载 Setup 安装程序，打开并确认安装到当前 Windows 账户
2. 不需要安装其他运行时，不要求管理员权限；开始菜单里能找到“小狗桌宠”
3. 小狗会在桌面底边出现。右键打开菜单；单击互动，按住来回摸摸，双击第二下按住拖动
4. 切到英文输入法，点击选中小狗后按 R 转身，Esc 取消选中，没有选中框
5. 右下角系统托盘有小狗图标；如果被折叠，点小箭头找找
   点击托盘图标收起/显示，右键托盘也能退出

安全提示
这份试用包还没有 Windows 代码签名证书，首次运行可能出现
“Windows 已保护你的电脑”或未知发布者提示。这不代表已通过微软安全认证。
请确认是邀请你试用的人提供的官网/文件，再自行决定是否运行；
可以取消并把提示发回，不需要关闭 Defender、SmartScreen 或其他保护。

点击次数与隐私
默认关闭。右键小狗 → 点击次数 → 开启计数，确认后才开始。
只累计键盘按下与鼠标/触控板左、右、中等按钮按下，统一显示累计数字。
鼠标移动、滚轮、抬起不计，双击计两次；并非所有触控板手势都算点击。
长按一个键只计一次，松开再按可以继续计数。单独按下 Shift/Ctrl 等修饰键仍计入，与 Mac 不同。
键盘输入会摇尾巴，鼠标按钮按下也能唤醒；隐藏不会停止已开启的计数。
锁屏/系统睡眠时暂停，正常解锁后恢复。安全桌面、特殊软件和远程桌面需实测。
为排除长按重复，仅在内存里用物理按键编号标记“按着／已松开”，松开即清除；
暂停计数、锁屏、系统睡眠或退出时全部清空。不转换文字，不读取虚拟键码、应用或设备身份；
不保存按键编号、顺序、单次时间或事件明细，不上传输入。
只在 %LOCALAPPDATA%\DesktopPet\settings.ini 保存今日、累计和设置。
拖动/爱心临时使用本窗口鼠标位置，不保存坐标或轨迹。

更新与卸载
右键小狗 → 更多 → 检查更新；确认后自动下载、校验 Ed25519 签名并安装，保存进度后退出旧版再打开新版。
日常没有后台联网或更新轮询，不上传计数或输入。只有主动检查和确认下载时访问官网，服务器能看到普通网络信息（例如 IP 地址）。
更新组件会保存“跳过某版”等更新偏好，不包含输入内容或次数。
已有朋友完成此前 build 4 的在线更新并确认计数保留；本版增加摸摸、双击拖动和提示气泡，仍请小范围试用，更多设备与其他场景待验证。
程序安装在 %LOCALAPPDATA%\Programs\DesktopPetDog，计数和设置位于独立的 %LOCALAPPDATA%\DesktopPet。
安装器保留一份程序 .previous 备份，文件替换或启动失败会尝试恢复，不删除用户计数；故障恢复仍待实机演练。
如果用过免安装 build 1，请先正常退出旧小狗，再安装 Setup，之后从开始菜单打开；旧副本不会自动删除。
卸载时退出后删除程序文件夹、同名 .previous 备份及开始菜单快捷方式即可；保留本地设置文件夹，以后计数可以沿用。

希望你帮忙看这些
1. 轮廓是否清楚、尺寸是否合适；呼吸、尾巴、摸摸、拖放和旋转是否自然
2. 在设计软件里打字/点击是否正常，有没有挡住透明处或抢走输入
3. 收起/恢复、Win+D、多屏与 125%/150%/200% 缩放表现
4. 锁屏或睡眠后能否继续使用，退出重开后数字和位置是否保留
5. 长按5秒只增加一次，松开再按增加一次；按住一个键时其他键和鼠标点击照常计数
6. 安静放着半小时后是否持续占用异常 CPU/内存（没有测量就不评价耗电）

遇到异常先右键托盘 → 退出小狗。反馈描述发生了什么、Windows 版本和缩放即可。
请不要提供输入内容或敏感截图。

官网：https://desktop-pet-dog.pages.dev/

互动特效：右键小狗 → 互动特效，分别勾选爱心、小花、小爪子、小星星。默认只有爱心；多选时每次随机出现一种，尽量避免连续重复。可全部关闭，搭配在本机保存。已经冒出的图案在拖动时继续自然飘完。

这次修正应用内更新时的旧目录占用：安装器先切换到安装目录外，再等待短暂占用释放。仍被占用时保留旧版与设置，并显示 Windows 错误代码。

尾巴大小：右键小狗 → 外观与摆放 → 尾巴大小，选择“小一圈”或“原来大小”。默认小一圈，选择会保存在本机；两种大小都保留柔软的摇动。

互动选项：右键 → 互动特效，可在四格原生复选框里连续搭配，不会勾选一次就关闭；返回或 Esc 回到主菜单，点击外面或右上角关闭。
旋转：点击小狗选中后按 R，按住不连续触发；Esc 或切换到其他应用取消选中。菜单“转个身”也会选中小狗，之后可以继续按 R。日常不抢键盘焦点，不增加全局按键监听。

新版菜单：面板和全部设置页缩小一圈，保留原字号，减少留白。顶部是摸摸它、摇尾巴和打个盹。外观与摆放、自动打盹、点击次数都有独立设置页，退出放在“更多”里。Tab/Shift+Tab切换控件，空格或回车操作；Esc返回主菜单，再按一次关闭。
R保持当前行为；中文输入法下若不能旋转，请切到英文输入法再点选小狗按R。

本次去重只作用于新收到的按下，原有累计数字不倒扣。
没有物理扫描码的媒体键会共用一个临时未知键标记；同一物理编号来自多把键盘时也共用标记，不读取设备身份来拆分。

本次互动更新
1. 默认按住小狗来回摸摸，会出现开心挤眼、淡淡脸红和少量特效；停住、移出小狗或松手后自然结束。普通单击保持原来的圆眼反馈，尾巴速度不变。
2. 双击第二下按住拖动，松开就回到摸摸。右键 → 外观与摆放 → 锁定位置可关闭，恢复按住即拖；已有明确关闭的选择继续保留。
3. 小狗旁新增操作提示。“关闭”只关本次启动，“不再提示”保存到本机；更多 → 操作提示… 可以随时重新查看，不会取消“不再提示”。
4. 抚摸只临时使用小狗本窗口中的位置与距离，不记录轨迹。移动、松手、特效及提示本身不增加计数；鼠标物理按下仍按原有规则计数。
5. Windows 系统关闭动画时，小狗会尊重“减少动态”：尾巴、弹性和特效位移会减少或停止。这与计数权限不同，计数和静态反馈仍可使用。
